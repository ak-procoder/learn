# Security Tools and Services

Cloud providers and third parties offer numerous security tools to enhance cloud security posture.

## AWS Security Services

**AWS Security Hub**: Centralized security findings
**Amazon GuardDuty**: Threat detection
**AWS WAF**: Web application firewall
**AWS Shield**: DDoS protection
**Amazon Inspector**: Vulnerability assessment
**AWS Secrets Manager**: Secrets management
**AWS CloudTrail**: Audit logging
**Amazon Macie**: Data discovery and protection
**AWS Config**: Configuration compliance

## Azure Security Services

**Azure Security Center**: Unified security management
**Azure Sentinel**: SIEM and SOAR
**Azure DDoS Protection**: DDoS mitigation
**Azure Firewall**: Managed firewall service
**Azure Key Vault**: Secrets and key management
**Azure Information Protection**: Data classification
**Azure Policy**:Governance and compliance
**Azure Monitor**: Logging and monitoring

## Google Cloud Security Services

**Security Command Center**: Security and risk dashboard
**Cloud Armor**: DDoS and WAF protection
**Chronicle**: Security analytics platform
**Binary Authorization**: Deploy-time security
**Cloud DLP**: Data loss prevention
**Secret Manager**: Secrets management
**Cloud KMS**: Key management
**VPC Service Controls**: Security perimeters

## Third-Party Security Tools

**SIEM/SOAR**:
- Splunk
- Sumo Logic
- LogRhythm

**CSPM (Cloud Security Posture Management)**:
- Prisma Cloud (Palo Alto)
- Lacework
- CloudGuard (Check Point)
- Wiz

**CWPP (Cloud Workload Protection)**:
- Aqua Security
- Sysdig
- Trend Micro Cloud One

**Container Security**:
- Snyk
- Anchore
- Twistlock (Prisma Cloud)

**Vulnerability Management**:
- Qualys
- Tenable
- Rapid7

Best practice: Use a combination of native and third-party tools for comprehensive security.
