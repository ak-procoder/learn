## What are Cloud Deployment Models?

Different ways cloud infrastructure can be deployed and accessed.

## The Four Main Models

### Public Cloud

**Definition**: Services offered over the public internet and available to anyone

**Characteristics**:
- Shared infrastructure
- Pay-as-you-go
- Provider managed
- Highly scalable

**Examples**: AWS, Azure, GCP

### Private Cloud

**Definition**: Infrastructure dedicated to a single organization

**Characteristics**:
- Exclusive use
-Greater control
- Can be on-premises or hosted
- More expensive

**Examples**: VMware Private Cloud, OpenStack

### Hybrid Cloud

**Definition**: Combination of public and private clouds

**Characteristics**:
- Data and apps share between environments
- Flexibility
- Workload portability
- Complex to manage

### Multi-Cloud

**Definition**: Using services from multiple cloud providers

**Characteristics**:
- Avoid vendor lock-in
- Best-of-breed services
- Geographic requirements
- Increased complexity

## Selection Factors

- Security and compliance requirements
- Cost considerations
- Scalability needs
- Control requirements
- Existing infrastructure
- Technical expertise
