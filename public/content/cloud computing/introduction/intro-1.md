## Definition

Cloud computing is the on-demand delivery of IT resources over the Internet with pay-as-you-go pricing. Instead of buying, owning, and maintaining physical data centers and servers, you can access technology services on an as-needed basis from a cloud provider.

## Core Concept

- **On-Demand Self-Service**: Users can provision computing resources without human interaction
- **Broad Network Access**: Services available over the network via standard mechanisms
- **Resource Pooling**: Provider's resources serve multiple consumers using multi-tenant model
- **Rapid Elasticity**: Capabilities can be elastically provisioned and released
- **Measured Service**: Resource usage is monitored, controlled, and reported

## Key Characteristics

- **Scalability**: Ability to scale resources up or down based on demand
- **Flexibility**: Access resources from anywhere with internet connectivity
- **Cost-Effectiveness**: Pay only for what you use, reducing capital expenses
- **Reliability**: Built-in redundancy and disaster recovery
- **Maintenance-Free**: Provider handles infrastructure management

## Evolution of Computing

**Traditional Computing** → **Virtualization** → **Cloud Computing** → **Edge Computing**

From on-premises servers to globally distributed cloud services.
