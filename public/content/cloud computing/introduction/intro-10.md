## Pay-As-You-Go

**Definition**: Pay only for resources consumed, billed by the hour or second.

**Benefits**:
- No upfront costs
- No long-term commitments
- Flexibility to start and stop resources

**Best For**: Variable workloads, development/testing, new projects

## Reserved Instances

**Definition**: Commit to using specific resources for 1-3 years in exchange for significant discounts.

**Discounts**: Typically 30-75% off on-demand pricing

**Best For**: Steady-state workloads, predictable usage patterns

## Spot/Preemptible Instances

**Definition**: Bid on unused cloud capacity at steep discounts (up to 90% off).

**Caveat**: Provider can reclaim resources with short notice

**Best For**: Fault-tolerant workloads, batch processing, flexible applications

## Savings Plans

**Definition**: Flexible pricing model offering discounts in exchange for usage commitment.

**Benefits**: More flexible than reserved instances while still providing savings

## Free Tier

**Definition**: Limited free usage of cloud services for new customers.

**Purpose**:
- Learning and experimentation
- Small-scale applications
- Proofs of concept

## Cost Optimization Strategies

**Right-Sizing**: Match resource size to actual needs

**Auto-Scaling**: Automatically adjust resources based on demand

**Resource Scheduling**: Turn off resources when not needed

**Storage Tiering**: Use appropriate storage class for data access patterns

**Monitoring**: Track and analyze spending regularly
