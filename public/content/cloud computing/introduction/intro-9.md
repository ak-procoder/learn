## Compute Services

**Purpose**: Processing power for running applications

**Examples**:
- Virtual Machines (VMs)
- Container services
- Serverless functions
- Batch processing

**Use Cases**: Web servers, application hosting, data processing

## Storage Services

**Purpose**: Data storage and retrieval

**Types**:
- Object storage
- Block storage
- File storage
- Archive storage

**Use Cases**: Backups, media files, databases, long-term archival

## Database Services

**Purpose**: Managed database solutions

**Types**:
- Relational databases (SQL)
- NoSQL databases
- In-memory databases
- Data warehousing

**Benefits**: Automatic backups, scaling, patching

## Networking Services

**Purpose**: Connectivity and network management

**Components**:
- Virtual networks
- Load balancers
- Content delivery networks (CDN)
- VPN and direct connections

**Use Cases**: Application connectivity, traffic distribution, global content delivery

## AI and Machine Learning

**Purpose**: Artificial intelligence and ML capabilities

**Services**:
- Pre-trained models
- ML training platforms
- Computer vision
- Natural language processing

**Use Cases**: Predictive analytics, image recognition, chatbots

## Analytics and Big Data

**Purpose**: Data processing and analysis

**Services**:
- Data lakes
- Stream processing
- Business intelligence
- ETL (Extract, Transform, Load) tools

**Use Cases**: Real-time analytics, data warehousing, log analysis
