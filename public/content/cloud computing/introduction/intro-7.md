## Layered Architecture

Cloud computing architecture consists of multiple layers working together:

### 1. Physical Layer (Infrastructure)

**Components**:
- Data centers
- Servers and storage devices
- Network equipment
- Power and cooling systems

**Responsibility**: Cloud provider manages entirely

### 2. Virtualization Layer

**Components**:
- Hypervisors
- Virtual machines
- Containers
- Virtual networks and storage

**Purpose**: Abstracts physical resources into virtual resources

### 3. Platform Layer

**Components**:
- Operating systems
- Middleware
- Runtime environments
- Development tools

**Purpose**: Provides environment for application deployment

### 4. Application Layer

**Components**:
- Software applications
- Web services
- APIs
- User interfaces

**Purpose**: Delivers services to end users

## Front-End vs Back-End

**Front-End (Client Side)**:
- User interfaces
- Web browsers
- Mobile apps
- Client devices

**Back-End (Cloud Side)**:
- Servers and storage
- Databases
- Virtual machines
- Cloud services

**Connection**: Internet serves as the communication medium between front-end and back-end.
