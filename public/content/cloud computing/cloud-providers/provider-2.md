## AWS Introduction

**Launched**: 2006

**Market Position**: Leader in cloud computing, largest market share (~32%)

**Global Infrastructure**:
- 31+ geographic regions
- 99+ availability zones
- 450+ points of presence
- Growing continuously

## Core Value Propositions

**Breadth of Services**:
- 200+ services
- Comprehensive portfolio
- Continuous innovation

**Global Reach**:
- Worldwide infrastructure
- Low latency globally
- Data residency options

**Maturity**:
- Longest track record
- Enterprise-proven
- Extensive documentation

**Ecosystem**:
- Largest partner network
- Marketplace with 1000s of solutions
- Strong community

## AWS Service Categories

- EC2 (Virtual servers)
- Lambda (Serverless)
- ECS/EKS (Containers)
- Elastic Beanstalk (PaaS)
- Lightsail (Simple VPS)

### Storage
- S3 (Object storage)
- EBS (Block storage)
- EFS (File storage)
- Glacier (Archival)
- Storage Gateway

### Database
- RDS (Relational)
- DynamoDB (NoSQL)
- Aurora (MySQL/PostgreSQL compatible)
- ElastiCache (In-memory)
- Redshift (Data warehouse)

### Networking
- VPC (Virtual network)
- Route 53 (DNS)
- CloudFront (CDN)
- Direct Connect
- API Gateway

### Security & Identity

### AI/ML

## Pricing Model

**Pay-as-you-go**:
- No upfront commitment
- Pay for what you use
- Per-second or per-hour billing

**Savings Options**:
- **Reserved Instances**: 1-3 year commitment, up to 72% savings
- **Savings Plans**: Flexible commitment, up to 72% savings
- **Spot Instances**: Unused capacity, up to 90% savings

**Free Tier**:
- 12 months free for many services
- Always free for some services
- Trials for others

## AWS Regions and Availability Zones

**Region**: Geographic area with multiple AZs

**Availability Zone**: One or more data centers

**Design for High Availability**:
- Deploy across multiple AZs
- Automatic failover
- Load balancing
- Data replication

## AWS Management

**Console**: Web-based

**CLI**: Command-line interface

**SDKs**: Multiple languages

**CloudFormation**: Infrastructure as Code

**CDK**: Cloud Development Kit (code-based IaC)
