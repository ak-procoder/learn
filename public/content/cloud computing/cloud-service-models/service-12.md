## Understanding Cloud Pricing Models

### IaaS Pricing

**Compute Costs**:
- Per hour or per second billing
- Instance type and size
- Operating system (Windows premium)
- Reserved instances (30-70% savings)
- Spot instances (up to 90% savings)

**Storage Costs**:
- Per GB per month
- I/O operations
- Data transfer costs

**Network Costs**:
- Data transfer out
- Load balancer usage
- VPN connections

### PaaS Pricing

**Application Hosting**:
- Instance size and count
- Compute hours or GB-hours
- Auto-scaling included
- Some platforms free tier

**Add-on Services**:
- Database usage
- Storage
- Additional features
- Support tiers

### SaaS Pricing

**Per User Licensing**:
- Monthly or annual per user
- Tiered feature sets
- Minimum users often required

**Usage-Based**:
- API calls
- Storage consumed
- Transactions processed
- Active users

## Cost Optimization Strategies

**Right-Size Resources**: Match capacity to actual needs
**Use Reserved Capacity**: Long-term commitment savings
**Implement Auto-Scaling**: Pay only for what you use
**Monitor and Optimize**: Regular cost reviews
**Choose Appropriate Tier**: Don't overpay for unused features
