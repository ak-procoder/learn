## Compliance Requirements by Service Model

Understanding compliance responsibilities for each model.

## Shared Compliance Responsibility

**General Principle**: Provider ensures infrastructure compliance,  customer ensures use compliance.

### IaaS Compliance

**Customer  Responsible For**:
- Operating system compliance
- Application compliance
- Data protection
- Access controls
- Audit logs
- Security configurations

**Provider Responsible For**:
- Physical security
- Network infrastructure
- Hardware SOC certifications

**Common Requirements**:
- HIPAA (healthcare)
- PCI DSS (payment cards)
- SOC 2 (security controls)
- ISO 27001 (information security)

### PaaS Compliance

**Shared More Heavily**:
- Provider handles platform compliance
- Customer handles application and data compliance
- Must understand platform certifications
- Limited access to underlying systems

**Implications**:
- Less control over compliance evidence
- Rely on provider's certifications
- Application-level compliance critical

### SaaS Compliance

**Mostly Provider**:
- Provider handles most compliance
- Customer manages user access and data governance
- Verify provider certifications
- Understand data processing agreements

**Customer Due Diligence**:
- Review provider's compliance certifications
- Data processing agreements
- Right to audit clauses
- Data residency requirements

## Industry-Specific Compliance

**Healthcare (HIPAA)**:
- Business Associate Agreements (BAA) required
- Encryption requirements
- Audit controls
- Not all services HIPAA-eligible

**Financial Services**:
- PCI DSS for payment data
- SOX for financial reporting
- Data retention requirements
- Specific regional regulations

**Government**:
- FedRAMP (US federal)
- IL levels (impact levels)
- Data sovereignty
- Specific security controls

## Compliance Best Practices

- Choose compliant cloud services
- Understand shared responsibility
- Regular compliance audits
- Document all compliance measures
- Employee training
- Third-party assessments
- Continuous monitoring
