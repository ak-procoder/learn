## What is the Command Line?

A text-based interface where users type commands to interact with the operating system, also called:
- **Terminal**: The application window
- **Shell**: The command interpreter (bash, zsh, fish)
- **Console**: Physical or virtual text interface

## Why Use the Command Line?

### Advantages
- **Efficiency**: Faster than GUI for many tasks
- **Automation**: Scripts for repetitive tasks
- **Remote Access**: SSH to manage servers
- **Power**: Access to all system capabilities
- **Resource-light**: Works on minimal systems

### Common Misconceptions
- Not just for "hackers" or experts
- Modern and actively developed
- Tab completion and history help usability
- GUIs often just wrap CLI commands

## Basic Terminal Anatomy

```
username@hostname:~$ command arguments
```

- **username**: Current user
- **hostname**: Computer name
- **~**: Current directory (home)
- **$**: Regular user prompt (# for root)
- **command**: Program to run
- **arguments**: Options and parameters
