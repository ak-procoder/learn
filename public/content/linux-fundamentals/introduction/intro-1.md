## Definition

Linux is a free and open-source Unix-like operating system kernel created by Linus Torvalds in 1991. Combined with GNU utilities, it forms a complete operating system.

## Core Characteristics

- **Open Source**: Source code is freely available and modifiable
- **Multi-user**: Multiple users can work simultaneously
- **Multitasking**: Runs multiple processes concurrently
- **Portable**: Runs on various hardware platforms
- **Secure**: Built-in security features and permissions

## Key Components

- **Kernel**: Core of the operating system
- **Shell**: Command-line interface for user interaction
- **File System**: Hierarchical structure for data organization
- **System Libraries**: Shared code for applications
- **System Utilities**: Tools for system management

## Why Learn Linux?

- **Industry Standard**: Powers most servers and supercomputers
- **Career Opportunities**: High demand for Linux skills
- **Free**: No licensing costs
- **Community Support**: Large, active community
