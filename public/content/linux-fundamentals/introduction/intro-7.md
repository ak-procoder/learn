## Installation Options

- ### Bare Metal Installation
  - Install Linux directly on physical hardware, replacing or dual-booting with existing OS
    - **Pros**: Full performance, complete hardware access
    - **Cons**: Permanent changes to disk, requires backup

- ### Virtual Machine
  - Run Linux inside virtualization software (VirtualBox, VMware, Hyper-V)
    - **Pros**: Safe testing, isolated environment, easy removal
    - **Cons**: Reduced performance, shared resources

- ### Live USB
  - Run Linux from USB drive without installation
    - **Pros**: No installation needed, portable, testing
    - **Cons**: Slower performance, no persistence (unless configured)

- ### WSL (Windows Subsystem for Linux)
  - Run Linux terminal and tools on Windows
    - **Pros**: No dual-boot needed, integrated with Windows
    - **Cons**: Limited GUI support, some restrictions

- ### Cloud/Remote Server
  - Access Linux on cloud providers (AWS, Azure, DigitalOcean)
    - **Pros**: Professional environment, no local setup
    - **Cons**: Requires internet, ongoing costs
