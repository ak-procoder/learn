## Built-in Documentation

### Man Pages (Manual Pages)
```bash
man command_name
man ls
man mkdir
```

### Info Pages
```bash
info command_name
```

### Help Option
```bash
command_name --help
ls --help
```

### Documentation Directories
```bash
/usr/share/doc/
/usr/share/man/
```

## Online Resources

### Official Documentation
- Distribution-specific docs (Ubuntu, Fedora, Arch Wiki)
- Project websites and wikis

### Community Forums
- StackOverflow
- Unix & Linux Stack Exchange
- Distribution forums (Ubuntu Forums, Fedora Discussion)

### Learning Platforms
- Linux Journey
- The Linux Documentation Project
- DigitalOcean Tutorials

## Getting Community Help

- Be specific about your problem
- Include error messages
- Mention your distribution and version
- Show what you've tried
- Be patient and respectful
