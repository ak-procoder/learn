## /srv - Service Data

The `/srv` directory contains data for services provided by the system.

## Purpose

Store data for system services:
- Web server sites
- FTP server files  
- Version control repositories
- Service-specific data

## Typical Structure

```
/srv/
├── www/            # Web server data
│   ├── site1/
│   └── site2/
├── ftp/            # FTP server data
│   ├── public/
│   └── private/
└── git/            # Git repositories
    └── project.git/
```

## Use Cases

**Web Hosting:**
```
/srv/www/example.com/
├── public_html/
├── logs/
└── config/
```

**FTP Server:**
```
/srv/ftp/
├── pub/           # Public files
└── incoming/      # Upload directory
```

**Git Server:**
```
/srv/git/
├── project1.git/
└── project2.git/
```

## Alternative Locations

Note: Many systems use other locations instead:
- Web: `/var/www/` (very common)
- FTP: `/var/ftp/`
- Repositories: `/var/lib/`

## Best Practices

**Organization:**
- Group by service type
- Separate data from configuration
- Use clear naming conventions

**Permissions:**
- Restrict access appropriately
- Set ownership to service user
- Regular backups

## When to Use /srv

Use `/srv` when:
- Hosting multiple services
- Need clear organization
- Following Filesystem Hierarchy Standard (FHS)
