## What is Mounting?

Mounting attaches a file system to a directory in the Linux directory tree, making its contents accessible.

## mount Command

Display and manage mounted file systems.

**View all mounts:**
```bash
# Show all mounted filesystems
mount

# Show in list format
mount -l

# Show specific type
mount -t ext4

# Show human-readable
df -h
```

**Mount a filesystem:**
```bash
# Basic syntax
mount [options] <device> <mount_point>

# Example: mount USB drive
sudo mount /dev/sdb1 /mnt/usb

# Mount with filesystem type
sudo mount -t vfat /dev/sdb1 /mnt/usb

# Mount with options
sudo mount -o ro /dev/sdb1 /mnt/usb  # read-only
```

## Common Mount Options

**Permission options:**
```bash
ro              # Read-only
rw              # Read-write (default)
noexec          # Prevent execution of binaries
nosuid          # Ignore SUID/SGID bits
nodev           # Don't interpret character/block devices
```

**Other options:**
```bash
auto            # Can be mounted with mount -a
noauto          # Won't be mounted with mount -a
user            # Allow ordinary user to mount
defaults        # rw,suid,dev,exec,auto,nouser,async
```

**Example usage:**
```bash
# Mount read-only
sudo mount -o ro /dev/sdb1 /mnt/backup

# Mount with multiple options
sudo mount -o noexec,nosuid,nodev /dev/sdb1 /mnt/untrusted
```

## umount - Unmount Filesystems

```bash
# Unmount by mount point
sudo umount /mnt/usb

# Unmount by device
sudo umount /dev/sdb1

# Force unmount (use carefully!)
sudo umount -f /mnt/usb

# Lazy unmount (detach now, cleanup when possible)
sudo umount -l /mnt/usb
```

**Can't unmount? Check usage:**
```bash
# See what's using the mountpoint
lsof /mnt/usb

# Or use fuser
fuser -m /mnt/usb

# Kill processes using it
fuser -km /mnt/usb
```

## /etc/fstab - Automatic Mounting

Configuration file for filesystems to mount at boot.

**Format:**
```
<device> <mount_point> <type> <options> <dump> <pass>
```

**Example /etc/fstab:**
```
# <device>      <mount>      <type>  <options>       <dump> <pass>
/dev/sda1       /            ext4    defaults        0      1
/dev/sda2       /home        ext4    defaults        0      2
/dev/sdb1       /mnt/data    ext4    defaults        0      0
UUID=xxxx       /mnt/backup  ext4    defaults        0      0
```

**Field meanings:**
- **device**: Device name or UUID
- **mount_point**: Where to mount
- **type**: Filesystem type (ext4, vfat, ntfs, etc.)
- **options**: Mount options (defaults, ro, noexec, etc.)
- **dump**: Backup utility dump (0=no, 1=yes)
- **pass**: fsck order (0=skip, 1=first, 2=after root)

**Test fstab changes:**
```bash
# Mount everything in fstab
sudo mount -a

# Check for errors without mounting
sudo mount -a --fake
```

## findmnt - Modern Mount Viewer

```bash
# Tree view of mounts
findmnt

# List specific mountpoint
findmnt /home

# Show by source device
findmnt /dev/sda1

# JSON output
findmnt --json
```

## UUID vs Device Names

**Problem with /dev/sdX:**
- Names can change between reboots
- Adding/removing drives changes names

**Solution: Use UUID:**
```bash
# Find UUID
sudo blkid /dev/sda1

# Use in fstab
UUID=abc123-def456  /mnt/data  ext4  defaults  0  0
```

## Common Mounting Scenarios

**Mount ISO file:**
```bash
sudo mount -o loop disk.iso /mnt/iso
```

**Mount network share (NFS):**
```bash
sudo mount -t nfs server:/share /mnt/nfs
```

**Mount Windows share (CIFS):**
```bash
sudo mount -t cifs //server/share /mnt/windows -o username=user
```

**Remount with different options:**
```bash
# Remount as read-only
sudo mount -o remount,ro /mount/point
```
