## What is FHS?

The Filesystem Hierarchy Standard (FHS) defines the directory structure and directory contents in Unix-like operating systems.

## Why FHS Matters

**Benefits:**
- **Consistency**: Similar layout across distributions
- **Predictability**: Know where to find things
- **Interoperability**: Software knows standard locations
- **Documentation**: Standard reference for everyone

## FHS Key Principles

**Separation of Concerns:**
1. **Shareable vs. Unshareable**
   - Shareable: Can be shared between systems (`/usr`, `/opt`)
   - Unshareable: System-specific (`/etc`, `/var/log`)

2. **Static vs. Variable**
   - Static: Doesn't change except by admin (`/bin`, `/lib`)
   - Variable: Changes during operation (`/var`, `/tmp`)

## FHS Directory Categories

**Root Hierarchy:**
```
/            # Primary hierarchy root
/bin         # Essential user commands
/boot        # Boot loader files
/dev         # Device files
/etc         # Host-specific system config
/home        # User home directories
/lib         # Essential shared libraries
/media       # Removable media mount points
/mnt         # Temporary mount points
/opt         # Add-on application packages
/proc        # Process information (virtual)
/root        # Root user home directory
/run         # Runtime data
/sbin        # Essential system binaries
/srv         # Service data
/sys         # System information (virtual)
/tmp         # Temporary files
/usr         # Secondary hierarchy (user programs)
/var         # Variable data
```

## /usr Hierarchy

**Secondary hierarchy for user programs:**
```
/usr/bin         # Non-essential user commands
/usr/include     # Standard include files
/usr/lib         # Libraries for /usr/bin
/usr/local       # Local hierarchy (third-level)
/usr/sbin        # Non-essential system binaries
/usr/share       # Architecture-independent data
/usr/src         # Source code
```

## /var Hierarchy

**Variable data:**
```
/var/cache       # Application cache data
/var/lib         # Variable state information
/var/local       # Variable data for /usr/local
/var/lock        # Lock files
/var/log         # Log files
/var/mail        # User mailboxes
/var/opt         # Variable data for /opt
/var/run         # Runtime data (often link to /run)
/var/spool       # Queued data (print, mail)
/var/tmp         # Temporary files preserved between reboots
```

## Compliance

**Most distributions follow FHS:**
- Debian/Ubuntu
- Red Hat/Fedora/CentOS
- SUSE/openSUSE

**Some variations:**
- Modern systems: `/bin` → `/usr/bin`
- Systemd: `/var/run` → `/run`

## Version

Current FHS version: 3.0 (June 2015)
