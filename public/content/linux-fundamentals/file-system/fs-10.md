## /proc - Process and System Info

The `/proc` directory is a virtual file system providing information about running processes and system state.

## Key Characteristics

- **Virtual**: Files don't exist on disk, created on-the-fly
- **Dynamic**: Content changes with system state
- **Text-based**: Human-readable information
- **Size 0**: Files show 0 bytes but contain data

## Process Directories

Each running process has a directory: `/proc/[PID]/`

**Useful files:**
- `/proc/[PID]/cmdline` - Command that started process
- `/proc/[PID]/status` - Process status
- `/proc/[PID]/environ` - Environment variables
- `/proc/[PID]/fd/` - File descriptors

## System Information Files

**CPU & Memory:**
- `/proc/cpuinfo` - CPU information
- `/proc/meminfo` - Memory usage
- `/proc/loadavg` - System load average

**Kernel:**
- `/proc/version` - Kernel version
- `/proc/sys/` - Kernel parameters

**Network:**
- `/proc/net/dev` - Network device stats
- `/proc/net/tcp` - TCP connections

## Practical Examples

```bash
# View CPU info
cat /proc/cpuinfo

# Check memory
cat /proc/meminfo

# See process info for PID 1234
ls /proc/1234/

# View kernel version
cat /proc/version
```

## Why /proc Matters

Essential for system monitoring, debugging, and understanding system state.
