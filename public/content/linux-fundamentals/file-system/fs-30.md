## Organization Best Practices

**Keep home directory organized:**
```bash
~/
├── Documents/
│   ├── Work/
│   ├── Personal/
│   └── Projects/
├── Downloads/
├── Pictures/
├── Scripts/
└── bin/          # Personal executables
```

**Use descriptive names:**
- Good: `project_report_2024.pdf`
- Bad: `doc1.pdf`, `untitled.pdf`

**Follow naming conventions:**
- Avoid spaces (use `_` or `-`)
- Use lowercase for consistency
- Be descriptive but concise
- Use dates in ISO format: `YYYY-MM-DD`

## Security Best Practices

**Protect sensitive data:**
```bash
# Restrict permissions on private files
chmod 600 ~/.ssh/id_rsa
chmod 700 ~/.ssh

# Don't leave sensitive data in /tmp
# Use secure deletion when needed
shred -u sensitive_file.txt
```

**Regular backups:**
```bash
# Create backup directory structure
/backup/
├── daily/
├── weekly/
└── monthly/

# Use rsync for backups
rsync -av --delete /home/user/ /backup/daily/
```

**Mount external drives safely:**
```bash
# Mount with restrictive options
sudo mount -o noexec,nosuid,nodev /dev/sdb1 /mnt/external
```

## Performance Best Practices

**Use appropriate file systems:**
- **ext4**: General purpose, reliable
- **XFS**: Large files, high performance
- **Btrfs**: Snapshots, compression
- **F2FS**: Flash storage (SSD, SD cards)

**Partition strategy:**
```
/boot       500MB      # Boot files
/           20-50GB    # System files
/home       Remaining  # User data
swap        1-2× RAM   # Swap space
```

**Separate partitions benefits:**
- Root full doesn't affect /home
- Easier to reinstall OS
- Different filesystem types
- Better security (mount options)

**SSD optimization:**
```bash
# Enable TRIM in fstab
UUID=xxx / ext4 defaults,noatime,discard 0 1

# Or run fstrim weekly
sudo fstrim -av

# Add to cron
echo "0 2 * * 0 /sbin/fstrim -av" | sudo tee -a /etc/crontab
```

## Maintenance Best Practices

**Regular monitoring:**
```bash
# Weekly disk space check
df -h | grep -E '(9[0-9]|100)%'

# Monitor inode usage
df -i | grep -E '(9[0-9]|100)%'

# Check SMART status monthly
sudo smartctl -H /dev/sda
```

**Log rotation:**
```bash
# Ensure logrotate is configured
ls /etc/logrotate.d/

# Manual log rotation if needed
sudo logrotate -f /etc/logrotate.conf
```

**Cleanup schedule:**
- **Daily**: Empty trash, clean /tmp
- **Weekly**: Package cache, old logs
- **Monthly**: Old kernels, unused packages
- **Quarterly**: Deep storage analysis

## Backup Best Practices

**3-2-1 Rule:**
- **3** copies of data
- **2** different media types
- **1** off-site backup

**Automation:**
```bash
#!/bin/bash
# Automated backup script

BACKUP_DIR="/backup/$(date +%Y-%m-%d)"
mkdir -p "$BACKUP_DIR"

# Backup important directories
rsync -av /home/user/Documents/ "$BACKUP_DIR/Documents/"
rsync -av /etc/ "$BACKUP_DIR/etc/"

# Create archive
tar -czf "$BACKUP_DIR.tar.gz" "$BACKUP_DIR"
rm -rf "$BACKUP_DIR"

# Keep only last 7 backups
find /backup -name "*.tar.gz" -mtime +7 -delete
```

## Documentation Practices

**Document your setup:**
```bash
# Keep notes in home directory
~/SETUP.md
~/README.md

# Document mount points
cat /etc/fstab > ~/fstab.backup.txt

# List installed packages
dpkg --get-selections > ~/installed-packages.txt

# Save partition layout
sudo fdisk -l > ~/partition-layout.txt
```

## Recovery Preparation

**Bootable rescue USB:**
- Keep updated rescue/live USB
- Test it periodically
- Include important tools

**Emergency contacts file:**
```bash
# ~/RECOVERY.md
# Important paths and commands for emergencies
# Backup location: /backup
# Important data: /home/user/Documents
# Config files: /etc
# Restore command: rsync -av /backup/latest/ /home/user/
```

**Test recovery procedures:**
- Practice restoring from backup
- Test booting from rescue media
- Verify backup integrity regularly

## Final Tips

1. **Never work as root** unless necessary
2. **Test commands** on non-critical data first
3. **Keep backups** of important files before major changes
4. **Read man pages** when unsure: `man command`
5. **Use version control** (git) for important files
6. **Document changes** you make to system
7. **Stay updated** with system and security patches
8. **Monitor disk health** proactively
9. **Clean regularly** to prevent disk full issues
10. **Learn from mistakes** and improve procedures
