## What is Globbing?

Glob patterns (wildcards) allow you to match multiple filenames using special characters.

## Basic Wildcards

**Asterisk (`*`)** - Matches zero or more characters:
```bash
ls *.txt                 # All .txt files
ls file*                 # Files starting with "file"
ls *report*              # Files containing "report"
rm *.tmp                 # Remove all .tmp files
```

**Question Mark (`?`)** - Matches exactly one character:
```bash
ls file?.txt             # file1.txt, fileA.txt, but not file10.txt
ls ???.txt               # Files with 3-char names
ls report-?.pdf          # report-1.pdf, report-A.pdf
```

**Square Brackets (`[]`)** - Matches any one character inside brackets:
```bash
ls file[123].txt         # file1.txt, file2.txt, file3.txt
ls [A-Z]*.txt            # Files starting with uppercase letter
ls file[0-9].txt         # file0.txt through file9.txt
ls [!a-z]*               # Files NOT starting with lowercase
```

## Advanced Patterns

**Character Classes:**
```bash
ls [[:digit:]]*          # Files starting with digit
ls [[:alpha:]]*          # Files starting with letter
ls [[:alnum:]]*          # Files starting with letter or digit
ls *[[:upper:]].txt      # Files ending with uppercase before .txt
```

**Brace Expansion (`{}`):**
```bash
touch file{1..5}.txt     # Creates file1.txt through file5.txt
cp file.txt{,.bak}       # Copies file.txt to file.txt.bak
mkdir -p project/{src,bin,doc}  # Create multiple directories
mv *.{jpg,png} images/   # Move all jpg and png files
```

## Practical Examples

**Backup files:**
```bash
cp *.conf{,.backup}      # Add .backup to all .conf files
```

**Select specific files:**
```bash
ls report-202[3-4]-*.pdf # Reports from 2023 or 2024
ls chapter-[01][0-9].md  # chapter-00.md through chapter-19.md
```

**Exclude patterns:**
```bash
shopt -s extglob         # Enable extended globbing
ls !(*.txt)              # Everything except .txt files
rm !(important*)         # Remove all except files starting with "important"
```

**Range operations:**
```bash
rm temp{1..100}.log      # Remove temp1.log through temp100.log
mkdir week{01..52}       # Create week01 through week52
echo {A..Z}              # Print A through Z
```

## Hidden Files

**Important note:**
- `*` does NOT match hidden files (starting with `.`)
- Use `.*` to match hidden files
- Be careful: `rm .*` includes `.` and `..`!

```bash
ls -d .*                 # List hidden files (includes . and ..)
ls -d .[!.]*             # List hidden files (excludes . and ..)
ls -A                    # List all including hidden (safer)
```

## Case Sensitivity

**By default, globbing is case-sensitive:**
```bash
ls *.TXT                 # Only matches uppercase .TXT
ls *.txt                 # Only matches lowercase .txt
```

**Case-insensitive globbing:**
```bash
shopt -s nocaseglob      # Enable case-insensitive matching
ls *.txt                 # Matches .txt, .TXT, .Txt, etc.
shopt -u nocaseglob      # Disable
```

## Common Pitfalls

**Unquoted globs expand:**
```bash
# WRONG: if no matches, passes literal string
rm *.tmp

# SAFE: check first
ls *.tmp && rm *.tmp

# SAFER: use find
find . -name "*.tmp" -delete
```

**Spacing matters:**
```bash
ls * .txt                # Space = two arguments: * and .txt
ls *.txt                 # One pattern: all .txt files
```
