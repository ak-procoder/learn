## What are Symbolic Links?

A symbolic link (symlink) is a file that points to another file or directory - like a shortcut.

## Creating Symbolic Links

```bash
# Syntax
ln -s <target> <link_name>

# Examples
ln -s /usr/share/doc docs
ln -s /var/log/syslog mylog
ln -s ~/Documents/project.txt shortcut.txt
```

## Characteristics

**Symlink properties:**
- Small file (just stores path)
- Can point to files or directories
- Can cross file systems
- Shows as `lrwxrwxrwx` in `ls -l`
- Can point to non-existent targets (broken link)

**Example output:**
```bash
$ ls -l
lrwxrwxrwx 1 user group 15 Jan 10 mylink -> /etc/passwd
```

## Symbolic vs Hard Links

| Symbolic Link | Hard Link |
|---------------|-----------|
| Separate file | Same inode |
| Can cross filesystems | Same filesystem only |
| Can link directories | Files only |
| Breaks if target deleted | Remains valid |
| Shows target in ls -l | Looks like regular file |

## Use Cases

**System organization:**
```bash
# /lib often links to /usr/lib
/lib -> /usr/lib

# Python version management
/usr/bin/python -> /usr/bin/python3.10
```

**User convenience:**
```bash
# Quick access to deep directory
ln -s /var/www/html/mysite ~/mysite

# Access files in multiple locations
ln -s ~/Documents/important ~/Desktop/important
```

## Managing Symlinks

```bash
# Check if file is symlink
ls -l filename

# See target of symlink
readlink filename

# Remove symlink (not target!)
rm linkname

# Find broken symlinks
find -L . -type l
```

## Common Pitfall

```bash
# WRONG: Removes target file!
rm -rf $(readlink mylink)

# RIGHT: Removes only the link
rm mylink
```
