## /lib - Essential Libraries

The `/lib` directory contains essential shared libraries needed by programs in `/bin` and `/sbin`.

## What are Libraries?

**Shared Libraries:**
- Reusable code shared by multiple programs
- Similar to DLLs in Windows
- Extension: `.so` (shared object)
- Example: `libc.so.6` - C standard library

## Directory Structure

**Architecture-specific:**
- `/lib/` - 32-bit libraries (on older systems)
- `/lib64/` - 64-bit libraries
- `/lib/x86_64-linux-gnu/` - Modern Debian/Ubuntu path

**Modules:**
- `/lib/modules/` - Kernel modules (drivers)
- `/lib/modules/$(uname -r)/` - Modules for current kernel

## Important Libraries

**C Library:**
- `libc.so.6` - Standard C library (glibc)
- Core functions used by almost all programs

**Dynamic Linker:**
- `ld-linux.so.2` or `ld-linux-x86-64.so.2`
- Loads shared libraries for programs

**Kernel Modules:**
- Device drivers
- File system drivers
- Network protocols

## How Programs Use Libraries

```bash
# See libraries used by a program
ldd /bin/ls

# Find library location
ldconfig -p | grep libc
```

## Modern Systems

In many distributions, `/lib` is a symbolic link to `/usr/lib` for consistency.

## Library Path

`LD_LIBRARY_PATH` environment variable specifies where system looks for libraries.
