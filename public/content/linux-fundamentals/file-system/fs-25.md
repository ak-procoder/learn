## locate - Fast File Search

Uses a pre-built database to quickly find files by name.

**Basic usage:**
```bash
# Find files containing 'nginx'
locate nginx

# Case-insensitive search
locate -i readme

# Limit results
locate -n 10 config

# Count matches only
locate -c passwd
```

**Update the database:**
```bash
# Refresh locate database (requires root)
sudo updatedb

# Database stored in /var/lib/mlocate/
```

**Advantages:**
- Very fast
- Searches entire system

**Limitations:**
- Database may be outdated
- Shows files you can't access
- Only searches by filename

## find - Powerful File Search

Real-time search with many options.

**Basic syntax:**
```bash
find [path] [expression]
```

**Search by name:**
```bash
# Find file by exact name
find /home -name "file.txt"

# Case-insensitive
find /home -iname "readme*"

# Find all .txt files
find . -name "*.txt"

# Exclude certain names
find . -name "*.txt" ! -name "temp*"
```

**Search by type:**
```bash
# Find only files
find /var -type f

# Find only directories
find . -type d

# Find symbolic links
find . -type l
```

**Search by size:**
```bash
# Files larger than 100MB
find . -type f -size +100M

# Files smaller than 1KB
find . -type f -size -1k

# Files exactly 512 bytes
find . -type f -size 512c
```

**Search by time:**
```bash
# Modified in last 7 days
find . -mtime -7

# Modified more than 30 days ago
find . -mtime +30

# Accessed in last 24 hours
find . -atime -1

# Changed in last hour
find . -cmin -60
```

**Search by permissions:**
```bash
# Find files with 777 permissions
find . -perm 777

# Find SUID files
find / -perm -4000

# Find world-writable files
find . -perm -002
```

**Search by owner:**
```bash
# Files owned by alice
find /home -user alice

# Files owned by group developers
find /var -group developers
```

**Execute commands on results:**
```bash
# Delete all .tmp files
find . -name "*.tmp" -delete

# Show detailed info
find . -name "*.log" -exec ls -lh {} \;

# Copy files
find . -name "*.conf" -exec cp {} /backup/ \;

# Confirm before action
find . -name "*.bak" -ok rm {} \;
```

**Combining conditions:**
```bash
# AND condition (both must match)
find . -name "*.txt" -size +1M

# OR condition
find . -name "*.txt" -o -name "*.pdf"

# Complex: .log files > 10MB, modified in last week
find /var/log -name "*.log" -size +10M -mtime -7
```

## locate vs find

| locate | find |
|--------|------|
| Very fast | Slower |
| Database-based | Real-time search |
| Name only | Many search criteria |
| May be outdated | Always current |
| Entire system | Specific path |
