## Linux File Types

Linux has different file types, each identified by a character in `ls -l` output.

## Seven File Types

**1. Regular File (`-`)**
- Normal files (text, binary, images)
- Example: `-rw-r--r-- 1 user group 1234 file.txt`

**2. Directory (`d`)**
- Folders containing files
- Example: `drwxr-xr-x 2 user group 4096 mydir`

**3. Symbolic Link (`l`)**
- Pointer to another file
- Example: `lrwxrwxrwx 1 user group 10 link -> target`

**4. Character Device (`c`)**
- Character-by-character access
- Example: `crw-rw-rw- 1 root tty 5, 0 /dev/tty`

**5. Block Device (`b`)**
- Block-based access (disks)
- Example: `brw-rw---- 1 root disk 8, 0 /dev/sda`

**6. Named Pipe (`p`)**
- FIFO (First In First Out) pipe
- Example: `prw-r--r-- 1 user group 0 mypipe`

**7. Socket (`s`)**
- Inter-process communication
- Example: `srwxr-xr-x 1 user group 0 mysocket`

## Identifying File Types

```bash
# Using ls -l (first character)
ls -l filename

# Using file command
file filename

# Using stat command
stat filename
```

## Practical Example

```bash
$ ls -l /
drwxr-xr-x  2 root root  4096 bin/
crw-rw-rw-  1 root tty   5, 0 dev/tty
lrwxrwxrwx  1 root root     7 lib -> usr/lib
-rw-r--r--  1 root root   123 file.txt
```
