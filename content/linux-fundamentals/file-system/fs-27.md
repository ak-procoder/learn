## df - Disk Free Space

Shows disk space usage for file systems.

**Basic usage:**
```bash
# Show disk usage
df

# Human-readable format
df -h

# Show file system type
df -T

# Show inodes instead of blocks
df -i
```

**Example output:**
```bash
$ df -h
Filesystem      Size  Used Avail Use% Mounted on
/dev/sda1        50G   20G   28G  42% /
/dev/sda2       100G   75G   20G  79% /home
tmpfs           4.0G  1.2M  4.0G   1% /run
```

**Useful options:**
```bash
# Specific filesystem
df -h /home

# Exclude certain types
df -h -x tmpfs -x devtmpfs

# Total only
df -h --total
```

## du - Disk Usage

Shows space used by files and directories.

**Basic usage:**
```bash
# Current directory size
du -sh .

# All files in directory
du -ah

# Subdirectory sizes
du -h --max-depth=1

# Sort by size
du -h | sort -hr
```

**Common examples:**
```bash
# Find largest directories
du -h /home | sort -hr | head -10

# Size of specific directory
du -sh /var/log

# Include only specific file types
du -ch **/*.log

# Exclude certain files
du -h --exclude="*.tmp"
```

**Understanding output:**
```bash
$ du -sh *
4.0K    file.txt
120M    videos/
2.5G    projects/
800K    documents/
```

## Finding Large Files

**Combine find and du:**
```bash
# Files larger than 100MB
find . -type f -size +100M -exec du -h {} \; | sort -hr

# Top 10 largest files
find . -type f -exec du -h {} \; | sort -hr | head -10

# Large files modified recently
find . -type f -size +50M -mtime -30 -exec ls -lh {} \;
```

**Using du efficiently:**
```bash
# Find large directories
du -h --max-depth=2 / 2>/dev/null | sort -hr | head -20

# Specific directory analysis
du -ah /var | sort -hr | head -20
```

## ncdu - Interactive Disk Usage

If available, `ncdu` provides interactive navigation:

```bash
# Install on Debian/Ubuntu
sudo apt install ncdu

# Use ncdu
ncdu /home

# Navigate with arrow keys
# Press 'd' to delete
# Press 'q' to quit
```

## Checking Inodes

**What are inodes?**
- Data structures representing files
- Limited number per filesystem
- Can run out even with disk space available

```bash
# Check inode usage
df -i

# Find directories with many files
find / -xdev -printf '%h\n' | sort | uniq -c | sort -k 1 -n
```

## Quick Disk Space Checks

```bash
# Is disk full?
df -h | grep -E '(9[0-9]|100)%'

# Where's the space going?
du -h --max-depth=1 / 2>/dev/null | sort -hr | head

# Clean up package cache (Debian/Ubuntu)
sudo apt clean

# Remove old logs
sudo journalctl --vacuum-time=7d
```

## Monitoring Fill Rate

```bash
# Watch disk space over time
watch -n 60 df -h

# Alert if over 90%
df -h | awk '$5+0 > 90 {print $0}'
```
