## /mnt - Temporary Mount Point

The `/mnt` directory is used for temporarily mounting file systems.

**Typical Uses:**
- Manually mounting partitions
- Network file systems (NFS)
- Testing and maintenance
- Recovery operations

**Example:**
```bash
# Mount a USB drive
sudo mount /dev/sdb1 /mnt

# Access files
ls /mnt

# Unmount when done
sudo umount /mnt
```

## /media - Removable Media

The `/media` directory is for automatically mounted removable media.

**Auto-mounted devices:**
- USB flash drives: `/media/username/USBDRIVE`
- External hard drives
- CD/DVD drives
- SD cards

**Structure:**
```
/media/
└── alice/
    ├── USB_DRIVE_1/
    ├── MyExternal/
    └── CDROM/
```

## Key Differences

| /mnt | /media |
|------|--------|
| Manual mounts | Auto-mounts |
| Admin use | User-friendly |
| Temporary | Removable devices |
| Single mount point | Per-user subdirs |

## Modern Desktop Systems

Desktop environments (GNOME, KDE) automatically mount removable media under `/media/username/`.

## Mount Commands

```bash
# View all mounts
mount

# View disk and mount status
df -h

# See what's mounted
lsblk
```
