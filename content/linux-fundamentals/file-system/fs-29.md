## fsck - File System Check

Checks and repairs file system errors. Similar to Windows' CHKDSK.

**Important:**
⚠️ **NEVER run fsck on mounted filesystem!** Can cause severe data corruption.

**Basic usage:**
```bash
# Check file system (unmount first!)
sudo umount /dev/sda1
sudo fsck /dev/sda1

# Automatic repair
sudo fsck -y /dev/sda1

# Check without fixing
sudo fsck -n /dev/sda1

# Force check even if appears clean
sudo fsck -f /dev/sda1

# Verbose output
sudo fsck -V /dev/sda1
```

**For root filesystem:**
- Schedule check on next reboot:
```bash
sudo touch /forcefsck
sudo reboot
```

- Or use shutdown:
```bash
sudo shutdown -F -r now
```

## Checking Disk Health

**SMART data (for hard drives):**
```bash
# Install smartmontools
sudo apt install smartmontools

# Check disk health
sudo smartctl -H /dev/sda

# Detailed SMART info
sudo smartctl -a /dev/sda

# Run short test
sudo smartctl -t short /dev/sda
```

**Check for bad blocks:**
```bash
# Non-destructive read-only test
sudo badblocks -sv /dev/sda1

# Non-destructive read-write test (safer)
sudo badblocks -nsv /dev/sda1

# Destructive write test (ERASES all data!)
sudo badblocks -wsv /dev/sda1
```

## Disk Performance Testing

**Read speed:**
```bash
# Test disk read speed
sudo hdparm -tT /dev/sda

# Example output:
# Timing cached reads:   12 MB in  2.00 seconds = 6.00 MB/sec
# Timing buffered disk reads: 100 MB in 3.00 seconds = 33.33 MB/sec
```

**Using dd for benchmarks:**
```bash
# Write test (1GB file)
dd if=/dev/zero of=testfile bs=1M count=1024 oflag=direct

# Read test
dd if=testfile of=/dev/null bs=1M count=1024 iflag=direct
```

## File System Optimization

**ext4 tuning:**
```bash
# View filesystem parameters
sudo tune2fs -l /dev/sda1

# Set maximum mount count before fsck
sudo tune2fs -c 30 /dev/sda1

# Set filesystem label
sudo tune2fs -L "MyData" /dev/sda1

# Enable/disable journaling
sudo tune2fs -O ^has_journal /dev/sda1  # disable
sudo tune2fs -O has_journal /dev/sda1   # enable

# Set reserved blocks percentage
sudo tune2fs -m 1 /dev/sda1  # 1% (default is 5%)
```

## Monitoring File System

**iostat - I/O statistics:**
```bash
# Install sysstat package
sudo apt install sysstat

# Show I/O stats
iostat

# Continuous monitoring (every 2 seconds)
iostat -x 2

# Specific device
iostat -x /dev/sda 2
```

**iotop - I/O by process:**
```bash
# Install iotop
sudo apt install iotop

# Run iotop
sudo iotop

# Show only active processes
sudo iotop -o
```

## Cleanup and Maintenance

**Remove old kernels (Ubuntu/Debian):**
```bash
# List installed kernels
dpkg --list | grep linux-image

# Remove old kernels (keeps current and one previous)
sudo apt autoremove --purge
```

**Clean package cache:**
```bash
# Debian/Ubuntu
sudo apt clean
sudo apt autoclean

# Red Hat/CentOS
sudo yum clean all

# Check cache size
du -sh /var/cache/apt
```

**Clean old logs:**
```bash
# Using journalctl
sudo journalctl --vacuum-time=7d  # Keep only 7 days
sudo journalctl --vacuum-size=100M  # Keep max 100MB

# Manually clean log files
sudo find /var/log -type f -name "*.log" -mtime +30 -delete
```

**Find and remove duplicate files:**
```bash
# Install fdupes
sudo apt install fdupes

# Find duplicates
fdupes -r /home/user

# Delete duplicates (interactive)
fdupes -rd /home/user
```

## Scheduled Maintenance

**Create maintenance script:**
```bash
#!/bin/bash
# /usr/local/bin/disk-maintenance.sh

# Clean package cache
apt clean

# Remove old logs
journalctl --vacuum-time=30d

# Update locate database
updatedb

# Check disk usage
df -h | mail -s "Disk Usage Report" admin@example.com
```

**Schedule with cron:**
```bash
# Edit root crontab
sudo crontab -e

# Run weekly on Sunday at 2 AM
0 2 * * 0 /usr/local/bin/disk-maintenance.sh
```
