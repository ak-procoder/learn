## /boot - Boot Loader Files

The `/boot` directory contains files needed to boot the system, including the kernel and boot loader.

## Important Files

**Kernel:**
- `vmlinuz-*` - Compressed Linux kernel
- `initrd.img-*` or `initramfs-*` - Initial RAM disk
- `System.map-*` - Kernel symbol table

**Boot Loader (GRUB):**
- `/boot/grub/` - GRUB configuration
- `/boot/grub/grub.cfg` - GRUB menu configuration

**EFI Systems:**
- `/boot/efi/` - EFI system partition mount point

## Why These Files Matter

**vmlinuz:**
- The actual Linux kernel
- Loaded into memory during boot
- Multiple versions for kernel upgrades

**initrd/initramfs:**
- Temporary root file system
- Loads crucial drivers before main filesystem
- Enables booting from complex setups (RAID, LVM)

**grub.cfg:**
- Boot menu configuration
- Defines available kernels
- Boot parameters

## Caution

⚠️ **Warning**: Files in `/boot` are critical for system startup. Deleting or corrupting them can make your system unbootable!

## Common Tasks

```bash
# List kernels
ls /boot/vmlinuz-*

# Check boot partition space
df -h /boot

# View GRUB config (read-only!)
cat /boot/grub/grub.cfg
```

## Boot Partition

Often on separate, small partition (~500MB-1GB) for compatibility and safety.
