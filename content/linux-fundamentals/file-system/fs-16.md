## /sys - System Devices and Drivers

The `/sys` directory is a virtual file system (sysfs) that exports information about kernel subsystems, hardware devices, and drivers.

## Key Characteristics

- **Virtual**: Doesn't exist on disk
- **Kernel interface**: Direct kernel information
- **Hierarchical**: Organized device tree
- **Read/Write**: Can configure devices by writing to files

## Major Subdirectories

**Devices:**
- `/sys/block/` - Block devices
- `/sys/class/` - Device classes (network, input, etc.)
- `/sys/bus/` - Bus types (pci, usb)
- `/sys/devices/` - Device hierarchy

**Power Management:**
- `/sys/power/` - Power management
- `/sys/class/power_supply/` - Battery info

**Modules:**
- `/sys/module/` - Loaded kernel modules

## Practical Uses

**Check battery status:**
```bash
cat /sys/class/power_supply/BAT0/capacity
```

**Brightness control:**
```bash
# Read current brightness
cat /sys/class/backlight/*/brightness

# Set brightness (requires root)
echo 500 > /sys/class/backlight/intel_backlight/brightness
```

**Network interface info:**
```bash
# Check link status
cat /sys/class/net/eth0/operstate

# Get MAC address
cat /sys/class/net/eth0/address
```

## Compared to /proc

| /proc | /sys |
|-------|------|
| Process info | Device/driver info |
| Older interface | Modern interface |
| Mixed information | Organized hierarchy |

## Why sysfs Matters

Provides structured access to kernel and hardware information, essential for system configuration and monitoring.
