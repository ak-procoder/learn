## /opt - Optional/Add-on Software

The `/opt` directory is used for installing optional, add-on, or third-party software packages.

## Purpose

- Self-contained software packages
- Commercial applications
- Large applications with many files
- Software not provided by distribution

## Structure

Each application gets its own subdirectory:
```
/opt/
├── google/
│   └── chrome/
├── lampp/          # XAMPP web stack
├── teamviewer/
└── vscode/         # VS Code
```

## Characteristics

**Self-contained:**
- All application files in one directory
- Easy to install/uninstall
- Minimal impact on system

**Typical Contents:**
```
/opt/myapp/
├── bin/            # Executables
├── lib/            # Libraries
├── share/          # Data files
└── etc/            # Configuration
```

## Advantages

**Organization:**
- Clean separation from system files
- Easy backup/removal
- Clear ownership

**Installation:**
- Often just extract and run
- Less integration with system package manager

## Usage Pattern

Many applications create symlinks from `/usr/local/bin/` to `/opt/application/bin/` for easier command access.

## Examples

```bash
# List installed optional software
ls -l /opt/

# Check if Google Chrome is installed
ls /opt/google/chrome/

# Run application from /opt
/opt/myapp/bin/myapp
```

## Alternative

Some distributions prefer `/usr/local/` instead of `/opt/` for similar purposes.
