## Essential Navigation Commands

Master these commands to move efficiently through the Linux file system.

## pwd - Print Working Directory

Shows your current location in the file system.

```bash
pwd
# Output: /home/alice/Documents
```

**Options:**
- `pwd -P` - Show physical path (resolve symlinks)
- `pwd -L` - Show logical path (default)

## cd - Change Directory

Move to different directories.

**Basic usage:**
```bash
cd /etc                  # Go to /etc
cd Documents             # Go to Documents (relative)
cd /home/alice/Music     # Absolute path
```

**Special shortcuts:**
```bash
cd                       # Go to home directory
cd ~                     # Also goes to home
cd -                     # Go to previous directory
cd ..                    # Go up one level
cd ../..                 # Go up two levels
cd ~username             # Go to another user's home
```

**Practical examples:**
```bash
# Navigate then go back
cd /var/log
cd -                     # Returns to previous location

# Go home from anywhere
cd ~

# Complex navigation
cd ../../etc/apache2     # Up two levels, then to /etc/apache2
```

## ls - List Directory Contents

Display files and directories.

**Common options:**
```bash
ls                       # List current directory
ls -l                    # Long format (detailed)
ls -a                    # Show all (including hidden)
ls -la                   # Long format + hidden
ls -lh                   # Human-readable sizes
ls -lt                   # Sort by modification time
ls -ltr                  # Reverse time sort (oldest first)
ls -R                    # Recursive listing
ls /etc                  # List specific directory
```

**Understanding ls -l output:**
```
-rw-r--r-- 1 alice users 1234 Jan 15 10:30 file.txt
│          │ │     │     │    │            │
│          │ │     │     │    │            └─ Filename
│          │ │     │     │    └─ Modification date/time
│          │ │     │     └─ Size in bytes
│          │ │     └─ Group
│          │ └─ Owner
│          └─ Number of hard links
└─ Permissions
```

## Combining Commands

```bash
# List and navigate
ls /etc && cd /etc

# Check where you are
pwd && ls -la

# Navigate and list
cd /var/log && ls -lh *.log
```

## Pro Tips

**Tab completion:**
- Press Tab to autocomplete paths
- Double Tab to see options

**History:**
- Use ↑/↓ arrows for command history
- `!$` - Last argument of previous command
