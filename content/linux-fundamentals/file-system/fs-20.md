## Hidden Files in Linux

Files and directories starting with a dot (`.`) are hidden in Linux.

## Why Hidden Files?

**Purpose:**
- Configuration files
- Application settings
- User preferences
- Avoid clutter in home directory

**Not truly "hidden":**
- Just not shown by default in `ls`
- Security through obscurity (not real security)

## Common Hidden Files

**In Home Directory:**
```
~/.bashrc              # Bash configuration
~/.bash_history        # Command history
~/.ssh/                # SSH keys and config
~/.vimrc               # Vim configuration
~/.profile             # User profile
~/.config/             # Application configs
~/.local/              # User-specific data
~/.cache/              # Application cache
```

## Viewing Hidden Files

**List with ls:**
```bash
# Show all files (including hidden)
ls -a

# Long format with hidden files
ls -la

# Show almost all (excludes . and ..)
ls -A
```

**File Managers:**
- Press `Ctrl+H` to toggle visibility
- Menu option "Show Hidden Files"

## Creating Hidden Files

```bash
# Simply start filename with a dot
touch .myfile
mkdir .mydir

# Hide existing file by renaming
mv myfile .myfile
```

## Important Notes

**Backup Caution:**
- Don't forget hidden files when backing up
- Use `cp -a` or `rsync -a` to include hidden files

**Home Directory:**
- Most user configuration is in hidden files
- Deleting `.bashrc` can affect your shell

## Practical Example

```bash
# See all files in home
ls -la ~

# Count hidden files
ls -A | wc -l

# Find all hidden files
find ~ -name ".*" -maxdepth 1
```
