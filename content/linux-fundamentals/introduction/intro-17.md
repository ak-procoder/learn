## Why Text Editors Matter

In Linux, everything is configured through text files, so mastering a text editor is essential.

## Editor Categories

### GUI Editors (Graphical)
- **gedit**: GNOME default, simple
- **Kate/KWrite**: KDE editors
- **VS Code**: Modern, feature-rich, popular with developers
- **Sublime Text**: Fast, polished
- **Atom**: Hackable, now discontinued

### Terminal Editors (CLI)

#### nano
- Beginner-friendly
- Shows commands at bottom
- Quick edits
```bash
nano filename
```

#### vim/vi
- Powerful, modal editor
- Steep learning curve
- Ubiquitous (on every Linux system)
- Highly efficient once learned
```bash
vim filename
```

#### emacs
- Extremely powerful and extensible
- Operating system, not just editor
- Keyboard-driven
- Large feature set

## Choosing an Editor

- **New users**: Start with nano or GUI editor
- **System admin**: Learn vim basics (always available remotely)
- **Developer**: VS Code or vim with plugins
- **Power user**: vim or emacs for maximum efficiency
