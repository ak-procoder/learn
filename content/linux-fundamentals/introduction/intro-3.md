## What is a Distribution?

A Linux distribution (distro) is a complete operating system built on the Linux kernel, bundled with software packages, package manager, and installation system.

## Major Distribution Families

### Debian-based
- **Ubuntu**: User-friendly, popular for desktops and servers
- **Debian**: Stable, community-driven
- **Linux Mint**: Desktop-focused, beginner-friendly
- **Kali Linux**: Security testing and penetration testing

### Red Hat-based
- **RHEL**: Enterprise-grade commercial distribution
- **Fedora**: Cutting-edge, community version
- **CentOS**: Free enterprise alternative (now CentOS Stream)
- **Rocky Linux**: Community-driven RHEL clone

### Independent
- **Arch Linux**: Minimalist, rolling release
- **openSUSE**: Professional and community versions
- **Slackware**: Oldest surviving distribution

## Choosing a Distribution

Consider: purpose, support, package management, community, stability vs. latest features
