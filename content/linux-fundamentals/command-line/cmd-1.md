## What is the Command Line?

The command line (or terminal) is a text-based interface for interacting with your Linux system.

## Why Use Command Line?

**Advantages:**
- **Powerful**: Access all system features
- **Efficient**: Faster than GUI for many tasks
- **Scriptable**: Automate repetitive tasks
- **Remote**: Work on servers without GUI
- **Precise**: Exact control over operations

## Terminal vs Shell

**Terminal:**
- Application that provides text interface
- Examples: GNOME Terminal, Konsole, xterm

**Shell:**
- Program that interprets commands
- Examples: bash, zsh, fish
- bash is the default on most Linux systems

## Opening the Terminal

**Keyboard shortcut:**
- `Ctrl + Alt + T` (most distributions)
- `Ctrl + `backtick (in some terminals)

**From menu:**
- Applications → System Tools → Terminal
- Search for "Terminal"

## Your First Commands

```bash
# Print working directory
pwd

# List files
ls

# Print something
echo "Hello, Linux!"

# Get help
man ls
```
