## Essential Terms

### Multi-Tenancy

**Definition**: Multiple customers (tenants) share the same physical infrastructure while maintaining data isolation.

**Benefits**: Cost efficiency, resource optimization

### Elasticity

**Definition**: Ability to automatically scale resources up or down based on demand.

**Example**: Web server automatically adding instances during high traffic.

### Scalability

**Vertical Scaling (Scale Up)**: Increasing resources of a single instance (more CPU, RAM)

**Horizontal Scaling (Scale Out)**: Adding more instances of resources

### Provisioning

**Definition**: Process of allocating and configuring cloud resources.

**Types**:
- Manual provisioning
- Automated provisioning
- Self-service provisioning

### High Availability (HA)

**Definition**: System design ensuring minimal downtime and continuous operation.

**Measurement**: Often expressed as "number of nines" (99.9%, 99.99%, etc.)

### Fault Tolerance

**Definition**: System's ability to continue operating properly in the event of component failure.

**Mechanisms**: Redundancy, failover, backup systems

### Geographic Distribution

**Regions**: Separate geographic areas containing multiple data centers

**Availability Zones**: Isolated locations within regions

**Edge Locations**: Points of presence for content delivery

### API (Application Programming Interface)

**Definition**: Set of protocols allowing different software components to communicate.

**Usage in Cloud**: Accessing and managing cloud services programmatically
